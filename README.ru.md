## <a id="описание"></a> 📋 Описание
Этот асинхронный парсер на Python извлекает полную информацию о книгах с bookvoed.ru с эффективностью промышленного уровня. Построенный с использованием современных асинхронных паттернов, он обрабатывает тысячи книг, бережно относясь к ресурсам целевого сервера. Идеально подходит для книголюбов, аналитиков данных и всех, кто хочет знать всё о доступных книгах! 📖

## <a id="возможности"></a> ✨ Возможности
- **Молниеносный парсинг** — обрабатывает до 100 книг в минуту ⚡
- **Умная параллельная обработка** — интеллектуально управляет 50+ одновременными запросами
- **Автоматическая логика повторных попыток** — экспоненциальная задержка для неудачных запросов 🔄
- **Адаптивное ограничение частоты** — саморегулируется, чтобы избежать блокировки 🛡️
- **Хранение в Parquet** — файлы на 70% меньше, чем CSV, с нативным сжатием 💾
- **Обнаружение дубликатов** — никогда не сохраняет одну книгу дважды 🎯
- **Корректное завершение** — обрабатывает Ctrl+C как профессионал ✨
- **Отслеживание прогресса** — красивые индикаторы прогресса tqdm 📊

### <a id="технологический-стек"></a> 🛠️ Технологический стек
- **Бэкенд:** Python 3.11+ с `asyncio`
- **HTTP-клиент:** aiohttp с keep-alive и кэшированием DNS
- **Парсинг HTML:** BeautifulSoup4 + lxml (парсинг на скорости C)
- **Хранение данных:** Apache Parquet через PyArrow
- **Логирование:** Ротируемые файловые обработчики со структурированным выводом
- **Индикатор прогресса:** `tqdm` с динамическими обновлениями

## <a id="как-это-работает"></a> 🎪 Как это работает
1. **Обнаружение страниц** — обходит страницы каталога, обнаруживая книги
2. **Извлечение ссылок** — собирает все URL книг с каждой страницы
3. **Параллельная обработка** — одновременно загружает до 50 страниц книг
4. **Умный парсинг** — извлекает название, автора, цену, наличие и 20+ других полей
5. **Дедупликация** — пропускает уже сохранённые книги с помощью отслеживания URL
6. **Хранение в Parquet** — сжимает и сохраняет данные в колоночном формате

## <a id="установка"></a> 🚀 Установка
1. **Клонируйте репозиторий:**
```bash
git clone https://github.com/janekkttme/bookvoed-toolkit.git
cd bookvoed-toolkit
```
2. Создайте виртуальное окружение:
```bash
python -m venv venv
source venv/bin/activate  # На Windows: venv\Scripts\activate
```
3. Установите зависимости:
```bash
pip install -r requirements.txt
```
4. Запустите парсер:
```bash
python main.py
```

## <a id="использование"></a> 🎮 Использование
### Базовое использование
```bash
# Запуск с настройками по умолчанию с 1-й страницы
python main.py

# Запуск с определённой страницы
python main.py --start-page 100

# Настройка количества параллельных задач и задержки
python main.py --concurrent 30 --delay 0.2
```

### Расширенная конфигурация
```bash
# В config.py — настройте под свои нужды
REQUEST_CONFIG = {
    'max_retries': 5,              # Повторять неудавшиеся запросы 5 раз
    'timeout': 60,                 # Таймаут 60 секунд
    'delay_between_requests': 0.1, # 100 мс между запросами
    'concurrent_tasks': 50         # 50 параллельных задач
}

CONNECTOR_CONFIG = {
    'limit': 0,                    # Неограниченное количество соединений
    'ttl_dns_cache': 300,          # Кэшировать DNS на 5 минут
    'use_dns_cache': True,         # Включить кэширование DNS
    'force_close': False,          # Держать соединения активными
}
```

## <a id="оптимизация-производительности"></a> 🚀 Оптимизация производительности
1. ***Пул соединений*** — повторное использование TCP-соединений ускоряет запросы на 30%
2. ***Кэширование DNS*** — исключает DNS-запросы для повторяющихся доменов
3. ***Парсинг в пуле потоков*** — парсинг HTML выполняется в параллельных потоках
4. ***Сжатие Parquet*** — файлы на 70-80% меньше, чем CSV
5. ***Умная пакетная обработка*** — обрабатывает книги оптимальными пакетами
